# Oskar's Original Tic-Tac-Timer!

## How is the game played?

- **The rules are nothing like tic-tac-toe, except for the winning condition.** Before the game starts, the player will pick a difficulty. At the start of the game, the player will be shown an empty 3x3 grid, and the game will randomly select you or the robot to go first (alternating turns henceforth). Then they will be shown a screen that says count to [variable number].
- Either you or the robot will be asked to count to a certain number. You will be visually indicated by the game saying, “Count to [random number].” **Your goal is to count that number in seconds, and once you think you’ve counted to that number, press the A button.** The robot will guess (using a random number generator within the range), then the number of milliseconds each player took to guess is compared to see which one is closest to the goal number. The winner gets one X or O **randomly** placed on the grid. Once you have three X’s or O’s aligned diagonally, vertically, or horizontally, the game is over, and a winner is declared based on who got their X’s or O’s aligned first.
